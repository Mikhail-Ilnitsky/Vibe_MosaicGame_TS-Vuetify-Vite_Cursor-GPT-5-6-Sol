# Контекст проекта

## Назначение

`mosaic-game` — адаптивная браузерная игра-мозаика. Пользователь выбирает изображение и сложность, после чего восстанавливает картину обменом квадратных фрагментов. Приложение является SPA и не использует бэкенд или базу данных.

## Стек

- Vue 3 с Composition API и `<script setup lang="ts">`;
- TypeScript 5 в строгом режиме;
- Vuetify 3;
- Vite 8;
- весь код приложения находится в `src/`.

## Ключевые решения

- **Сетка.** После загрузки изображения берутся его натуральные размеры. Меньшая сторона делится на 5–11 частей, размер исходного квадрата округляется вниз, количество квадратов по большей стороне вычисляется автоматически. Остаток считается симметричной центральной обрезкой.
- **Фрагменты.** Файлы физически не нарезаются. Каждый фрагмент — `div` с одним исходным `background-image`; `background-size` зависит от количества колонок и строк, а `background-position` — от исходных координат фрагмента.
- **Состояние.** В массиве игрового поля меняются местами целые объекты фрагментов. Ход засчитывается только при обмене двух разных позиций.
- **Управление.** Клик-клик и перетаскивание реализованы единым набором Pointer Events. Перемещение становится drag после прохождения половины отображаемого размера плитки.
- **Адаптивность.** `ResizeObserver` измеряет доступную игровую область. Поле сохраняет рассчитанные пропорции, полностью помещается на экране и не растягивается больше обрезанного исходника.
- **Победа.** После каждого обмена порядок проверяется по исходным идентификаторам. При решении поле подсвечивается на 500 мс, затем фрагменты заменяются цельным фоном с тем же центральным кадрированием.
- **i18n.** Локализация хранится в `src/composables/useI18n.ts`; начальный RU/EN определяется по `navigator.language`.
- **Деплой.** Vite использует корневой `base` в development и путь репозитория в production. `.github/workflows/deploy-pages.yml` собирает проект на Node.js 22 и публикует `dist` через GitHub Pages Actions.
